# COOL-MATH-GAME-terra-week-2
COOL MATH GAME

## Description
This project is a **COOL MATH GAME** made to provide a fun and interactive way of learning math. As of right now, the **Addition** and **Subtraction** games are fully functional. The other math subjects have not been completed yet but are planned for future updates.

## Why I Made This Project 
I created this project because I think math be learn while engaged, so i decided to make a game that is both educational and fun.

## How to Play / Run 

### How to Play:
1. **Enter Your Name:** Type your name on the main screen to get a personalized welcome message.
2. **Select Difficulty:** Choose between **Easy** or **Hard** modes.
3. **Choose Your Subject:**
   * **Addition Game:** Available in both Easy and Hard modes. 
   * **Subtraction Game:** Enter your name, go to **Easy mode**, and you will be given the option to select **Subtraction**.
4. **Answer Questions:** Read the question header, look at your score, and click the correct answer button before the time runs out!

### What I Coded (Build Steps):
* **Main Screen:** Coded the main screen to take the user name and show the welcome message with difficulty options.
* **Difficulty Cards:** Made the easy and hard settings cards to let players choose their math subject.
* **Game Layout:** Set up the game screen layout with the score text, the question header, and a box for the answer.
* **Question Generator:** Wrote the question generator to make random addition questions using `Math.random()`.
* **Option Buttons:** Built the option buttons to shuffle the correct answer with random wrong answers on the screen.
* **Answer Checker:** Coded the answer checker to add points for right answers and make the score red for negative points.
* **Shake Animation:** Added a shake animation to make the button shake if you click the wrong answer.
* **Timer Fix:** Fixed the timer typo so a new question spawns exactly after one second when you click the correct answer.
