# COOL-MATH-GAME-terra-week-2
COOL MATH GAME
to play you can type your name and select easy or hard, as of now really only the addition and subtraction game works, the other subjects have not been completed.
- next i coded the main screen to take the user name and show the welcome message with difficulty options
- after that i made the easy and hard settings cards to let players choose their math subject
- then i set up the game screen layout with the score text, the question header, and a box for the answer
- after that i wrote the question generator to make random addition questions using math random
- i built the option buttons to shuffle the correct answer with random wrong answers on the screen
- next i coded the answer checker to add points for right answers and make the score red for negative points
- then i added a shake animation to make the button shake if you click the wrong answer
- finally i fixed the timer typo so a new question spawns after one second when you click the correct answer
